# Brief P1 — schema, visit, layout, parse (the library core)

**Worktree:** `../Portcullis-worktrees/p1-core` on branch `p1-core`.
**Read first:** `docs/01-design.md` (whole spec + Appendix A frozen interfaces), and Tasks 1.1–1.12 in `docs/superpowers/plans/2026-10-31-portcullis.md`. The core headers in `include/portcullis/core/` are done and frozen — build on them, do not change them.

**Goal.** Everything from a schema type to `parse<S>(Untrusted) -> Result<Parsed<S>>`: the combinators (`schema/`), the one walker (`visit/for_each_field.hpp`), layout analysis (`visit/layout.hpp`), and the parser (`parse/`). **Produces (frozen):** the schema combinators; `for_each_field<S>`, `field_count_v`, `field_index_v`, `field_type_t`; `fixed_prefix_v`, `is_fixed_v`, `fixed_size_v`; `value_of_t`, `Parsed<S>`, `Partial<S>`, `field<"n">(v)`, `parse<S>`.

**Tasks (TDD, one commit each):** 1.1 primitives + Ref/Tag + Field/Struct → 1.2 for_each_field → 1.3 layout → 1.4 parse of primitives/Bytes<N>/flat Struct + Parsed + value_of_t → 1.5 Ref lengths + Partial + forward-reference and integer-target compile-fail rules → 1.6 Array (with the element cap, default 4096, D-008) → 1.7 Choice/Case → 1.8 Optional → 1.9 Refine → 1.10 nested structs + error paths → 1.11 Parsed immutability + umbrella → 1.12 report.
