# Brief P5 — handwritten bench parsers, bench runner, CI matrix

**Worktree:** `../Portcullis-worktrees/p5-bench` on branch `p5-bench`.
**Read first:** spec §8.3, Tasks 5.1–5.3 in the plan. Needs no library parse code; runs alongside P1. The Portcullis rows of the benchmark are filled by the integrator in Wave 3 once P1 lands.

**Goal.** The honest comparison point and the measurement harness: a plain, bounds-checked hand-written parser per format, a runner that reports throughput, and the report generator — plus completing the CI matrix.

**Task 5.1 — handwritten parsers** (`bench/handwritten/{tls_heartbeat,png_chunks,tiff_ifd}.hpp`, `tests/bench_handwritten.test.cpp`). Plain C++ with an explicit `if (remaining < n) return false;` before every read — a real, correct parser, not a strawman. Tests: each accepts a valid sample and rejects the family's truncated input (`png_chunks_rejects_length_past_end`, `tiff_ifd_rejects_entry_count_past_end`).

**Task 5.2 — runner + report** (`bench/bench.cpp`, `bench/CMakeLists.txt`, `scripts/gen-benchmarks.py`). `bench.cpp` parses each sample N=2000 times per parser and prints median MB/s as JSON lines `{format, parser, mbps}`. `gen-benchmarks.py` turns that, plus `fixed_prefix_v`/field counts (a tiny `bench/layout_report.cpp`, wired once P1 lands) and per-schema compile wall-time, into `BENCHMARKS.md` with the commit hash and `clang++ --version`. Until P1 lands, emit the handwritten rows only. Enable with `-DPORTCULLIS_BUILD_BENCH=ON`.

**Task 5.3 — CI matrix** (`.github/workflows/ci.yml`, extend the Wave 0 skeleton). Add the compile-fail tests to every job, `-Werror`, and a `bench-smoke` step that builds `bench/`.

**Done:** `tests/bench_handwritten.test.cpp` passes; `python3 scripts/gen-benchmarks.py` writes a table with the three handwritten rows; the CI file is valid YAML and the bench-smoke step builds. `docs/reports/P5-report.md`.
