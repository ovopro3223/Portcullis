# Brief P6 — structure-aware fuzzing

**Worktree:** `../Portcullis-worktrees/p6-fuzz` on branch `p6-fuzz`. **Starts after P1 is merged.**
**Read first:** spec §6, Tasks 6.1–6.4 in the plan, and Appendix A (fuzz block).

**Goal.** A fuzzer that walks the schema with the **same** `for_each_field` the parser uses — one description of a format, two products. No second schema description anywhere.

**Consumes (from P1, frozen):** `for_each_field`, `field_index_v`, `field_type_t`, `value_of_t`, `parse<S>`, all combinators, `tests/schemas/heartbeat.hpp`. You add `tests/schemas/png_chunks.hpp` and `tiff_ifd.hpp` if P7 has not; coordinate through the frozen interface only.

**Produces (frozen):** `Generator<S>` (`valid()`, `violating()`), `mutate<S>(buf, size, max_size, seed)`, and `PORTCULLIS_FUZZ_TARGET(S)`.

**Tasks:** 6.1 `Generator::valid()` — outputs that always `parse` ok, biased to boundaries (lengths 0 and the cap, every `Choice` case), deterministic per seed. 6.2 `Generator::violating()` — each output violates exactly one contract; over many seeds every applicable `ErrorKind` appears. 6.3 `mutate<S>()` — field-level ops (grow/shrink a length or count, swap a tag, truncate at a field boundary, duplicate an array element, byte-flip fallback); **never returns > max_size, never reads past size** (`mutate_respects_max_size`, 10k iterations under ASan — Review Focus 5). 6.4 libFuzzer hook + three targets (`fuzz/targets/*.cpp`) + `fuzz/CMakeLists.txt` (`-fsanitize=fuzzer,address,undefined`, Linux only) + `.github/workflows/fuzz-smoke.yml` (60 s each).

**Done:** generator/mutator unit tests pass (build `mutate` tests with the `clang-asan` preset); each of the three fuzz targets runs 60 s with no crash, no sanitizer report, on Linux (WSL or CI). `docs/reports/P6-report.md`.
