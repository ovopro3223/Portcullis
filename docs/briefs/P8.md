# Brief P8 — TaggedArena (ARM MTE)

**Worktree:** `../Portcullis-worktrees/p8-arena` on branch `p8-arena`. **Starts after P1 is merged.**
**Read first:** spec §7 and §11, Tasks 8.1–8.2 in the plan, Appendix A (arena block). This is the experimental, time-boxed wave; the core does not depend on it.

**Goal.** An arena that holds validated output and, on hardware with ARM MTE, makes any out-of-bounds access to it fault — the one part that extends detection beyond code that goes through the library.

**Consumes (from P1, frozen):** `Parsed<S>` (to copy), `value_of_t`, the field walker for the deep copy.

**Produces (frozen):** `TaggedArena` (`allocate`, `mte_available`, `tagging_active`), `materialize<S>(Parsed<S>, TaggedArena&) -> Parsed<S>*`.

**Task 8.1 — portable arena + materialize** (`arena/tagged_arena.hpp`, `tests/arena.test.cpp`). A bump arena over `mmap`/`aligned_alloc`. `allocate` returns `nullptr` on exhaustion — never UB. `materialize` deep-copies: integers and the bytes behind every span, so the result survives the input buffer being freed or overwritten. Tests: `allocate_returns_aligned_memory`, `exhaustion_returns_nullptr`, `materialize_copies_spans_out_of_the_input`, `tagging_inactive_without_mte`.

**Task 8.2 — MTE path + QEMU job.** Under `#if defined(__aarch64__) && defined(__ARM_FEATURE_MEMORY_TAGGING)`: `mmap` with `PROT_MTE`, `prctl(PR_SET_TAGGED_ADDR_CTRL, ... PR_MTE_TCF_SYNC ...)`, a random tag per 16-byte granule (`<arm_acle.h>`). Test `overflow_past_allocation_faults` (fork; child writes one granule past a 32-byte allocation; must die with SIGSEGV), skipped and reported as skipped when `!mte_available()`. `.github/workflows/mte.yml`: cross-compile `--target=aarch64-linux-gnu -march=armv8.5-a+memtag`, run under `qemu-aarch64 -cpu max`. If QEMU's MTE is unreliable, mark the job `continue-on-error: true` and say so in the report and README (spec §11).

**Done:** arena tests pass on x86-64; the MTE test passes under QEMU (or the job is marked experimental with the reason). `docs/reports/P8-report.md` states the documented limits: 16-byte granule, heap only, detection by fault not prevention, Linux/Android only.
